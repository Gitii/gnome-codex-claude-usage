# OpenCode artwork

The two `opencode-logo-*-square.svg` files are the official square marks,
downloaded from https://opencode.ai/brand on 2026-10-21. The page's SVG
download data came from `/_build/assets/index-DnG68iX4.js` (logoLightSquareSvg
and logoDarkSquareSvg); URL decoding only, no geometry or color edits.
The light variant is for light backgrounds; dark is for dark backgrounds.

The brand page offers these assets for download but supplies no explicit asset
license. No MIT/GPL/public-domain license is asserted for these marks.
OpenCode trademarks belong to their respective owners. This extension is not
affiliated with or endorsed by OpenCode.
